 Car Rental Web Portal

A full-stack car rental web application featuring a modern Tailwind CSS frontend portal. Includes interactive vehicle browsing, category filtering, and real-time rental booking calculations.

 Features
Diverse Fleet Catalog: Browse Sedans, SUVs, Luxury cars, Sports cars, and Electric Vehicles.
Category Filtering: Easily filter vehicles by type.
Interactive Booking: Calculate total costs instantly with custom days and add-ons.
Management & Analytics: Track total revenue, active rentals, and inventory status in real-time.
